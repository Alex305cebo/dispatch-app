# Дорожная карта Dispatch App
_Сведение исследования 5 агентов, 2026-07-17. Всё в рамках правила «бесплатно»._

## Уже есть (построено)
Per-truck экономика (calcLoad) · ИИ-чтение rate con + сканов (Gemini) · документы (RC/BOL/POD) · Telegram-чат через аккаунт диспетчера · трекинг ELD + карта · обслуживание траков (ремонты/масло/todo) · PIN-вход + журнал входов.

## СЕЙЧАС — ВСЕ ШЕСТЬ ПОСТРОЕНЫ (2026-07-18) ✅
1. Авто-инвойс + пакет (invoice+RC+POD один PDF, блок без POD) — lib/invoice.ts, /invoices, кнопка на грузе.
2. Фото BOL/POD из Telegram → ИИ → авто-прикрепление + напоминание — lib/tg-intake.ts, /api/tg-poll (нужен вход в Telegram).
3. Проверка брокера FMCSA при импорте RC + красные флаги — lib/fmcsa.ts (нужен FMCSA_WEBKEY).
4. Реальные траковые мили (ORS) + дизель (EIA) — lib/geo-routing.ts (нужны ORS_API_KEY, EIA_API_KEY).
5. AR aging «кто не заплатил» — lib/loads.ts listReceivables, /invoices, плашка на Обзоре.
6. Сроки документов (регистрация/инспекция/страховка/CDL/медкарта) — паспорт трака + плашка на Обзоре.

Ключи-заглушки (бесплатные, заводит владелец): FMCSA_WEBKEY, ORS_API_KEY, EIA_API_KEY. Без них функции честно деградируют, приложение работает.

## СЕЙЧАС (было, историческая заметка — высокая ценность, данные уже есть)

1. **Авто-инвойс брокеру + пакет документов** ← фича №1 по всем источникам (Truckbase этим славится).
   Груз → `delivered` → PDF-инвойс (наше юрлицо+MC, load#, ставка из RC, remit-to) + склейка invoice+RC+POD в один PDF → email брокеру / фактору (NOA). Блокировать отправку без POD. Инвойс редактируем до отправки (жалоба №1 на Alvys — неисправимые инвойсы).
2. **BOL/POD из Telegram сами прикрепляются к грузу.**
   Водитель кидает фото в чат (как и так делает) → Gemini определяет тип → к активному грузу водителя. + авто-напоминание «скинь POD», если груз delivered, а POD нет. Это убивает главный ежедневный «chase» диспетчера.
3. **Проверка брокера при импорте RC** — FMCSA QCMobile API (бесплатный WebKey через Login.gov):
   `GET mobile.fmcsa.dot.gov/qc/services/carriers/docket-number/{MC}` → authority ACTIVE?, бонд on file?, возраст MC. Красные флаги кодом: authority≠active (блок), бонда нет (блок), MC<6 мес, имя/адрес/телефон в RC ≠ FMCSA, gmail-домен «компании», rate сильно выше среднего при молодом MC, смена authority у известного брокера.
4. **Реальные мили вместо haversine×1.2:**
   - маршрут: OpenRouteService `driving-hgv` (бесплатный ключ, ~2000 запр/день) → мили + полилиния на карту;
   - города→координаты: офлайн-база SimpleMaps US Cities (JSON в приложении, без сети);
   - дизель: EIA API (бесплатный ключ), цена по PADD-региону еженедельно → в себестоимость.
5. **AR aging «кто не заплатил»** — дата отправки пакета + Net-терм из RC → колонки 0-30/31-45/45+ на Обзоре, алерты в Telegram. Копим свой лог «этот брокер реально платит за N дней» (платной репутации брокеров бесплатно не существует — это наша замена).
6. **Сроки документов** — CDL, med card, страховка, регистрация, инспекция: даты (ИИ может вытащить из фото) + подсветка за 60/30 дней + алерт.

## ПОЗЖЕ

- **Settlements водителей** — ведомость: грузы × ставка (cpm/%), доплаты/вычеты → PDF в Telegram еженедельно.
- **IFTA** — полилинии/GPS × границы штатов (Census GeoJSON + Turf.js) → мили по штатам; галлоны из чеков (ИИ). Делать к квартальному дедлайну (31 окт). Сырые данные хранить 4 года.
- **Detention-таймер** — геозоны пикапа/выгрузки из ELD GPS → таймер, за 30 мин до конца free time алерт (детеншн платят только если предупредить ДО) → строка в инвойс.
- **HOS-aware ETA** — остаток миль/47mph + 10-час брейк если drive clock не хватает → флаг «не успевает» до звонка брокера.
- **Аналитика** — $/миля по лейнам, по брокерам, deadhead % по тракам.
- **Погода по маршруту** — NWS api.weather.gov (бесплатно, без ключа) — алерты по точкам полилинии.

## СОЕДИНЕНИЯ (одно кормит другое)
- ELD GPS → deadhead → калькулятор → инвойс → aging → лог оплат брокера.
- Telegram → фото → ИИ → документы → пакет инвойса → settlements.
- RC-импорт → FMCSA-проверка → профиль брокера → aging/история.
- Одометр ELD → масло/PM → журнал ремонтов → cost-per-mile в экономику трака.

## НЕ делать / честно невозможно бесплатно
- Отдельное приложение для водителя — все лидеры на этом обожглись (краши, «не показывает инфы», водители не ставят). Наш путь — Telegram.
- Пере-усложнение UI (жалобы на Alvys): для 6 траков — минимум кликов.
- Толлы (нет открытой базы тарифов), lane-рейты (DAT/Truckstop платные), кредитный скоринг брокеров (Ansonia платный).
