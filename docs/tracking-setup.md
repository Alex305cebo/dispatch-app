# Как подключить отслеживание траков

Где это в приложении: **Траки → «Отслеживание траков»** (свёрнутая полоса вверху
страницы). Там два поля — ссылки и токен. Какое из них ваше, зависит от ELD.

Состояние на 24 августа 2026.

---

## Как это работает вообще

Приложение раз в пять минут (и по кнопке «Обновить») спрашивает у ELD, где
машины, и складывает ответ в таблицу `fleet_status`. Оттуда координаты попадают
на карту, в карточку трака, в список «кому искать груз» и в историю пути.

**Траки сопоставляются по номеру.** В ELD у машины есть имя или юнит — оно должно
совпадать с номером трака в приложении. Это причина номер один для «подключено, а
ничего не обновляется»: в Samsara машина названа `Truck 12`, а у нас номер
`TRK-12` — для программы это разные машины.

---

## ZigZag — ссылками, без ключей

Самый простой случай: у ZigZag есть публичная ссылка на трак, и её достаточно.

1. В кабинете ZigZag открыть трак → **Live Share** → скопировать ссылку. Она
   выглядит как `https://zigzageld.com/tracker?token=…`.
2. Повторить для каждой машины.
3. В приложении: **Траки → Отслеживание траков** → вставить ссылки в верхнее поле,
   **по одной на строку** → «Сохранить и обновить».

Что даёт: координаты и скорость. Часы водителя (HOS) по ссылке не приходят — для
них нужен ключ вендора.

Срок жизни ссылки задаётся при её создании (можно год). Истекла — трак перестанет
обновляться, в ответе будет «authorize failed». Лечится новой ссылкой.

## Samsara — токеном API

Ссылка вида `cloud.samsara.com/o/…/fleet/viewer/…` **в поле для ссылок не
работает**, и это не наша недоделка. Разобрал вживую: по этому адресу лежит не
данные, а страница-приложение; координаты она забирает закрытым внутренним
GraphQL (`us10-ws.cloud.samsara.com/r/graphql?q=FleetViewer`) с защитой от
посторонних запросов. Такой путь нигде не описан и не обещан — построенное на нём
отслеживание однажды утром перестанет работать, и никто не будет виноват.

Поэтому Samsara подключается её собственным API. Три шага, делает владелец парка:

1. Samsara → **Settings → API tokens** → **Create API token**.
2. Право (scope): **Read Vehicle Statistics** в разделе Vehicles. Больше ничего не
   нужно — токен не сможет ни менять, ни удалять.
3. Скопировать токен и вставить в приложении: **Траки → Отслеживание траков →
   поле «Samsara»** → «Сохранить и обновить».

Приложение сразу опросит парк и скажет, сколько траков обновилось. Ноль при живом
токене — почти всегда несовпадение имён (см. выше).

Токен показывается один раз. Потеряли — создайте новый, старый удалите.

## Motive (ex-KeepTruckin), Verizon Connect, Geotab и остальные

Пока не подключены. Шаблон один и тот же: у всех есть API с токеном и метод
«где мои машины». Работы — один небольшой файл на вендора (у Samsara это
`lib/eld-samsara.ts`, около сотни строк) плюс поле в настройках.

Что нужно от вас, чтобы добавить вендора: название системы и токен для проверки.
Без живого токена написать можно, а убедиться, что работает, — нет.

---

## Ключи, которые вводить не надо

FMCSA (проверка брокеров) и HERE (платные дороги) работают на наших ключах,
заданных при установке переменными окружения `FMCSA_WEBKEY` и `HERE_API_KEY`.
В интерфейсе этих полей нет намеренно: обе службы бесплатны в наших объёмах, и
клиенту там нечего заводить.

Google AI (чтение рейт-конов) тоже работает на нашем ключе (`GEMINI_API_KEY`), но
поле в админке оставлено: у кого свой ключ — вставит его и получит свою квоту.

## Если «подключено», а траки не двигаются

Проверять по порядку, сверху вниз — так быстрее всего:

1. **Имена.** Номер трака в приложении = имя машины в ELD. Разошлись хоть на
   пробел — обновления уходят в пустоту.
2. **Кнопка «Обновить»** на странице траков. Она опрашивает все источники сразу и
   показывает, сколько машин обновилось и сколько ошибок.
3. **Ссылка не истекла** (ZigZag) / **у токена есть право Read Vehicle
   Statistics** (Samsara).
4. **Внешний пингер.** Без него GPS обновляется только при заходе в приложение.
   Настраивается один раз: cron-job.org → `https://<домен>/api/eld-poll?secret=…`
   каждые 5 минут, где secret — переменная `CRON_SECRET` этой установки.
