# fleet-ops — операционные документы Maya Logistics

Здесь лежит то, что относится к работе самого перевозчика, а НЕ к приложению:
анализ поставщиков, расчёты затрат, черновики писем контрагентам.

Документация приложения (роадмап, деплой, интеграции) — уровнем выше, в `docs/`.
Разделение нужно, чтобы поиск по техническим докам не выдавал коммерческие
расчёты, и наоборот.

| Файл | О чём |
|---|---|
| `roadside-networks-2026.md` | Сети дорожного ремонта для флота из 10 траков: сравнение Cox Fleet / Millennials Maintenance / NTS / Road Rescue Network / TA RoadSquad / Speedco, шинные программы Michelin Advantage и Goodyear Fleet HQ, расчёт экономии при 10 выездах в месяц, черновики писем-RFQ |

## Как читать пометки в таблицах

**[факт]** — прямо заявлено провайдером или в отраслевой публикации, ссылка в
разделе «Источники». **[оценка]** — рыночный ориентир, подтверждается только
котировкой от провайдера; такие цифры нельзя нести в бюджет как есть.
